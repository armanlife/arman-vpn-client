## Arman VPN とは？

**Arman VPN** は、Firefox Account で使える無料のオープンソース VPN です。インターネットのトラフィックを、**Fastly** のインフラ上にある Mozilla のサーバーを経由して、安全な **HTTP/1.1、HTTP/2、HTTP/3** トンネルで運びます。

**Android、Windows、macOS、Linux** に対応しており、完全無料で広告もありません。

## 🚀 主な機能

✈️ クロスプラットフォーム: Android、Windows、macOS、Linux

📺 Android TV: リモコンで操作できます

⭐ シンプルなインターフェースでとても使いやすい

🆓 無料: Firefox Account ごとに毎月 50 GB

🌐 Mozilla のサーバー: ping テストで国を選ぶか、アプリに最適なサーバーを選ばせることができます

⚡ HTTP/1.1、HTTP/2、HTTP/3 による高速で安定した接続

🦊 Firefox のように見える: Mozilla への接続は Firefox 自身の TLS フィンガープリント（uTLS）で始まります

🔀 スマートルーティング（スプリットトンネリング）: VPN を経由しないサイトやアプリを選べます

🧱 ネットワークが接続をブロックする場合: TLS フラグメンテーション、上流の SOCKS5 プロキシ、[リレーサーバー](../relay/README.md)

💾 バックアップとインポート: アカウントと設定を 1 つのファイルにまとめ、別のデバイスやサーバーに移せます

⚙️ 高度な接続オプション: IPv4、IPv6、デュアルスタック、カスタム MTU

🔒 暗号化 DNS（DNS over HTTPS）

🌍 英語、ペルシア語、中国語、ロシア語を含む 15 言語

🌙 ライトテーマとダークテーマ

🛡 オープンソースで安全、コミュニティ主導

🔄 自動アップデート

**どのファイルをダウンロードすればよいですか？**

- **Android:** 分からない場合は **Universal** を選んでください。どのスマートフォンにもインストールできます。**ARMv8** は現在のほとんどのスマートフォン向けで、サイズが小さくなります。
- **Windows:** **Setup** は通常のインストーラーです。**Portable** はインストール不要で、任意のフォルダーから実行できます。
- **Linux:** Linux デスクトップ（グラフィカル環境あり）には **App** を、サーバー（グラフィカル環境なし、Web パネル付き）には **Core** を選んでください。
- **Docker でのサーバー:** 同じリリースタグの core イメージを使います。[Docker](#docker) を参照してください。

### 🌐 Web パネル

Linux サーバー向けに、Arman VPN には任意のブラウザで開ける **Web パネル** があり、アプリにある機能をすべて備えています。アカウントとデータの管理、サーバーの選択と遅延テスト、接続テスト、ライブログ、そしてすべての設定です。

<p align="center"><img src="../screenshots/web.webp" width="720" alt="Web パネル"></p>

- **パネルのアドレス:** `http://SERVER-IP:10820/app/`（ユーザー名とパスワードが必要です）。正確なアドレスはインストールの最後に表示されます。
- **プロキシ:** ポート `10810` の SOCKS5 と HTTP（専用のユーザー名とパスワードが必要です）。

## Docker

Linux の core（プロキシと Web パネル）はコンテナイメージとしても提供されています。リリースタグ `vX.Y.Z`（上のダウンロードと同じタグ）により、`ghcr.io/<owner>/<repository>:<version>` が公開され、あわせて `v` 付きの形式、メジャーとマイナーのバージョン、`latest` も公開されます。owner と repository は、ワークフローを実行する GitHub リポジトリです。例では upstream の名前を使っています。

```bash
docker run -d --name arman-vpn --restart unless-stopped \
  -p 10820:10820 -p 127.0.0.1:10810:10810 \
  -v arman-vpn:/var/lib/arman-vpn \
  ghcr.io/armanlife/arman-vpn-client:latest
```

初回の起動時に、パネルのログイン情報とプロキシのログイン情報が表示されます。アカウントと設定は `arman-vpn` ボリュームに保存されます。[Docker ガイド](../DOCKER.md)を参照してください。

## 既知の制限

<details>
<summary>Mozilla のサーバーが通さないもの</summary>

- **TCP:** ポート 80、443、8080、8443 のみです。メール（25、465、587、993）や SSH（22）などのほかのポートは拒否されます。例外は GitHub への SSH 経由の Git で、これは自動的にポート 443 を通ります。
- **UDP:** ポート 80、443、3478、8080、8443、49152-65534 のみです。ほかのポートを使う通話やゲームは通りません。ブラウザとほとんどのアプリは通常どおり動作します。

</details>
